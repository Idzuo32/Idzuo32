# github-profile

The README rendered on Marko's GitHub profile page (`marko-builds/marko-builds`).
One file. It is a public-facing positioning surface, not a project.

## Run it

There is nothing to run. `README.md` renders at github.com/marko-builds.

## Decisions

- **The repo name must stay `marko-builds`.** GitHub only renders a profile README
  from a repo whose name matches the username exactly. Renaming it silently removes
  the profile page.
- **It is positioning, so it is his voice.** Never edit the copy without showing a
  draft first. Match the register in the portfolio lane: warm but economical, short
  direct sentences, no hype, and no claim that is not checkable.
- **Every link and claim is load-bearing** - this is the first thing a recruiter or a
  maintainer reads. A dead link here costs more than a dead link anywhere else in
  these repos.

## Conventions

Keep it one screen. GitHub truncates long profile READMEs behind a fold that most
readers never open.
